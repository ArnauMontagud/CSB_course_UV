# Computational Systems Biology, practical material

Hands-on sessions for **Biología de Sistemas Computacional** (42589), Master's in
Bioinformatics, ETSE, Universitat de Valencia. Arnau Montagud, I2SysBio (CSIC-UV).

Click the badge of the session. Everything runs in your browser, there is nothing
to install.

## Two rules for every session

1. **Binder keeps nothing.** Download your notebook with `File > Download` when
   you start and again before you leave. The copy you download is what you hand in.
2. **Ten minutes without activity closes your session.** Download before the break.

## Working on your own machine

Each repository has an `INSTALL.md` with a tested conda environment. It is not
needed for the class.

## Previous editions

Every edition is kept as a git tag in each repository, so the material as
delivered that year can be relaunched exactly as it was:
